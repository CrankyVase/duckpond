# Layout and live-feedback checkpoint — 2026-09-08

User priorities: preserve the broad chat layout, improve the surrounding pages,
keep theme colors customizable, avoid decorative gradients, and use a browser.
Later steering prioritized downloads pushing the catalog away, frozen ETA/context,
and coding previews that show source or never refresh. No model execution allowed.

## What changed

- Settings has grouped section navigation, search and focused content. Mounted
  sections preserve unsaved model edits while switching tabs.
- Providers separates connections, ordered fallback routing and connection setup.
  Routing fetches the complete provider catalog, independent of model-table filters.
- Model picker gains search and local/remote filters; keyboard order follows the
  displayed provider groups. File/command activity is compact, with diffs built
  only when opened. Widgets use neutral theme surfaces and readable spacing.
- Files, Stats, Costs and Media layouts are quieter and more consistent. Files'
  quick generation controls are collapsed and only offer ready image models.
- Downloads now use SvelteMap: mutating a plain Map inside $state did not notify
  subscribers. One queue summary replaces the expanding stack above Discover;
  full detail lives in Downloads. Failed starts remain actionable. ETA sampling
  uses elapsed time so extra polling tabs do not erase the sample window, and
  stalled transfers clear their stale rate/ETA.
- Coding HTML opens in a dock beside chat. Completed writes and command results
  debounce file refreshes, update an open source view, and reload preview assets.
  Failed tree requests preserve the current tree; stale workspace responses are
  ignored. Phone users open the file panel explicitly.
- Authenticated preview-session creation issues an expiring read-only capability
  for one workspace. Asset documents receive an opaque-origin CSP sandbox; the
  iframe cannot access DuckPond's DOM/storage. Path-scoped CSP sources and CORS
  permit local relative CSS/modules while blocking account API calls. Symlinks
  are resolved before confinement checks; responses bypass caches. Runtime errors
  report to the parent via source-checked postMessage without replacing history.
  The legacy static endpoint also receives a document sandbox.
- Streaming telemetry now covers remote output and the agent loop, including
  reasoning and tool arguments. Estimates are labeled, measured usage wins, and
  no context/output generation settings change. Preview workspace metadata now
  survives reattach. Reconnect cleanup releases its lock before retrying, and
  repeated completion events do not duplicate message ids.

## Validation

- `npm --prefix server test`: existing suites plus stream progress, download rate
  and workspace-preview tests. No live DB/model/service starts.
- `npm --prefix web test` and production Vite build.
- `web/test/layout-browser.mjs`: Chromium with mocked APIs and external requests
  blocked. Checks settings edits/search, picker, routing reorder, tool diffs,
  widgets, populated Files/Stats/Costs, desktop/tablet/phone layouts, eight live
  download rows without crushing Discover, progress/ETA changes without reload,
  failed-start persistence, preview updates, context changes, reconnect and
  duplicate completion recovery.
- `web/test/browser-smoke.mjs`: Media/Hub and chat render-error/inline-preview
  regressions, all mock generation requests.
- `web/test/workspace-preview-browser.mjs`: actual isolated Fastify preview routes,
  a temporary HTML/CSS/module project, fresh imported code after reload, forbidden
  parent-DOM/account-API access and runtime-error reporting. No production app boot.

Browser scripts accept PLAYWRIGHT_MODULE and CHROMIUM_EXECUTABLE for an existing
Playwright installation. Screenshots are written to /tmp/duckpond-*.png.
Build retains existing accessibility/style warnings and large vendor chunks.
